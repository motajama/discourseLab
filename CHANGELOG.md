# Changelog

## 0.1.0-beta - local testing release

### Added

- Local project management
- Methodology modes
- TXT/DOCX import
- Document segmentation
- Open coding
- Memos
- Codebook
- GT workspace
- CDA workspace
- Actors and markers
- Discourse features
- Analytical model builder
- Co-occurrence network
- Methodology helper library
- Exports
- Project backup
- Integrity checker

### Changed

- Atari/Libertinus UI skin
- Fixed horizontal navigation
- Progress-oriented dashboard
- Compact document coding workspace
- Safer delete confirmations
- Scroll preservation

### Known limitations

- Restore from backup is not implemented yet.
- PDF import is not implemented.
- OCR is not implemented.
- Full-text search is not implemented yet.
- Inter-coder mode is not implemented.
- Cloud sync is not implemented.
- Authentication and multi-user permissions are not implemented.
- SVG and network visualizations are exploratory.
- DOCX import extracts text, not full formatting.
- This is a local testing release.
