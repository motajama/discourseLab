# discourseLab 0.1.0-beta Release Notes

This is discourseLab 0.1.0-beta, a local testing release for early workflow testing.

Keep backups of important data. Use the project backup ZIP regularly from the Exports page. Restore from backup is not implemented yet, so backup ZIP files are for safekeeping and manual recovery.

## What to try first

1. Create a project.
2. Import a TXT or DOCX document.
3. Create segments from selected text.
4. Create and assign codes.
5. Add memos.
6. Try GT and CDA workspaces if relevant to your project.
7. Create an analytical model relation.
8. Open the co-occurrence network.
9. Export the research package and project backup ZIP.
10. Restart the app and confirm the data persists.

## Reporting bugs

When reporting a bug, include:

- Operating system and browser.
- Python version.
- What you were trying to do.
- Exact steps to reproduce the problem.
- What happened.
- What you expected to happen.
- Any error message from the browser or terminal.
- Whether the issue happens after restarting the app.

Do not share sensitive research data in bug reports.
