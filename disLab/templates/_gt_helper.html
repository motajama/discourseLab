Grounded Theory prompts

For open coding

  • What is happening here?
  • What process is visible?
  • What is the actor doing?
  • Can the code be formulated as an action?

For axial coding

  • What conditions shape this phenomenon?
  • What actions or interactions respond to it?
  • What consequences follow?
  • What properties and dimensions define the category?

For categories

  • Which axial codes belong together?
  • Which category has the strongest explanatory power?
  • Are there negative cases?
